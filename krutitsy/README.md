# Крутицкое подворье: аудиопрогулка

Статический сайт без зависимостей. Живёт в подпапке `/krutitsy/` репозитория `simonov-excursion` и повторяет устройство экскурсий «Ордынка» и «Симонов монастырь».

Адрес: Москва, Крутицкая улица, 17. Прогулка: 8 точек.

Открыть: https://vlk2017.github.io/simonov-excursion/krutitsy/

## Что есть

Карточка точки, фото-карусель (первый слайд: современное фото со шторкой старого на 50% или честная плашка «Старого снимка нет»), плеер под фото, «Начать рассказ», подсказка «Вы на месте», маршрут пешком, режим «рефото», работа без интернета.

## Голос

Рассказы озвучены голосом Grigory в HeyGen Voice (тем же, что в «Ордынке»). Адреса mp3 в `data/points.json` (`audio`), копии в `audio/heygen/` (`audioLocal`). Тексты озвучки без цифр: `tts/`, исходные: `scripts/`. Если mp3 недоступен, плеер использует локальную копию.

## Тесты

```
npm test        # nav-core + статические проверки
npm run check   # синтаксис js
```

E2E на 390 px: `tests/e2e/krutitsy.e2e.js` (нужны Chrome и puppeteer-core).

## Пересборка

`python3 tools/build_points.py` собирает `data/points.json`, `python3 tools/build_docs.py` собирает `RIGHTS.md`, `SOURCES.md`, `docs/PHOTO_AUDIT.md`.

## Документы

`SOURCES.md` источники и координаты, `RIGHTS.md` права на снимки, `docs/PHOTO_AUDIT.md` проверка фото, `docs/VIDEO.md` про видео.

## Что нужно проверить на месте

Точки поставлены по узлам OpenStreetMap. Радиус «я на месте» 22 м, соседние точки стоят не ближе 26 м. Улицу переходите только по пешеходному переходу.
