# Скорбященский храм на Ордынке: аудиопрогулка

Статический сайт без зависимостей. Живёт в подпапке `/ordynka/` репозитория `simonov-excursion` и повторяет устройство экскурсии по Симонову монастырю.

Адрес: Москва, Большая Ордынка, 20 (храм иконы «Всех скорбящих Радость»). Прогулка: 8 точек, 20–35 м друг от друга.

Открыть: https://vlk2017.github.io/simonov-excursion/ordynka/

## Что есть

Карточка точки, фото-карусель, плеер сразу под фото, «Начать рассказ», остановка отмечается сама в конце рассказа (следующий сам не включается), кнопки «Предыдущая»/«Следующая точка», плашка «Подойдите к точке», камера с режимами и рефотосъёмкой, пешеходная навигация, работа без интернета (свой кэш `ordynka-v1`, не мешает Симонову). Кнопок скорости нет.

## Голос

Пока нет записи диктора, рассказ читает озвучка браузера (русский голос телефона). На экране подпись «временный голос». Тексты для записи лежат в `scripts/` (чистый текст) и в `tts/` (даты и числа словами для программ озвучки).

Как поставить свой голос: положите `audio/01-vorota.mp3` и т. д., затем в `data/points.json` (через `tools/build_points.py`) у точки укажите `"audioLocal": "audio/01-vorota.mp3"`. Плеер сам переключится с озвучки браузера на mp3, а кнопка «скачать рассказы для офлайна» появится сама. Тест проверяет, что файл есть и это mp3.

## Тесты

```
npm test                    # nav-core + статические проверки
npm run check               # синтаксис js
```

E2E на 390 px: `tests/e2e/ordynka.e2e.js` (нужны Chrome и puppeteer-core; описано в начале файла).

## Пересборка

`sh tools/build.sh` пересобирает движок из движка Симонова (патчи в `tools/patch_engine.py`, `tools/patch_html.py`), `data/points.json` (`tools/build_points.py`), `RIGHTS.md` и `SOURCES.md` (`tools/build_docs.py`).

## Документы

`SOURCES.md` источники и координаты, `RIGHTS.md` права на каждый снимок, `docs/VIDEO.md` про видео.

## Что нужно проверить на месте

Точки поставлены по узлам OpenStreetMap. Радиус «я на месте» 22 м, а точки стоят близко друг к другу, поэтому проверьте, как телефон ведёт себя у стен. Улицу переходить только по переходу. Точки внутри ограды зависят от того, открыта ли калитка.
