# Храм исповедников в Поведниках: аудиопрогулка

Статический сайт без зависимостей. Живёт в подпапке `/povedniki/` репозитория `simonov-excursion` и повторяет устройство экскурсий «Ордынка» и «Крутицы» (тот же шаблон, свой service worker, свой кэш `povedniki-v1` и свои ключи `povedniki-*` в localStorage).

Адрес: Московская область, городской округ Мытищи, посёлок Поведники, Соборная площадь, 1. Прогулка: 8 точек, по прямой между точками около 1,5 км, пешком больше.

Открыть: https://vlk2017.github.io/simonov-excursion/povedniki/

## О чём

Сначала история посёлка (название, деревня 1920-х годов, зона пансионатов, девяностые), потом соседние места (Троицкое, Чиверёво, канал Москва — Волга и водохранилище), в конце церковь-часовня и новый храм Новомучеников и исповедников. Где источники расходятся, это сказано в рассказе и в `SOURCES.md`.

## Фото

Только свободные файлы Викисклада, авторы и лицензии в `RIGHTS.md`. Свободных старых снимков именно этих мест нет, поэтому на всех точках плашка «Старого снимка нет». Фото соседних мест подписаны как соседние.

## Голос

Рассказы озвучены голосом Grigory в HeyGen Voice (тем же, что в «Ордынке» и «Крутицах»). Адреса mp3 в `data/points.json` (`audio`), копии в `audio/heygen/` (`audioLocal`). Тексты озвучки без цифр: `python3 tools/povedniki_tts.py`.

## Тесты

```
npm test        # nav-core + статические проверки
npm run check   # синтаксис js
```

E2E на 390 px: `tests/e2e/povedniki.e2e.js` (нужны Chrome и puppeteer-core): из корня репозитория `python3 -m http.server 8099`, затем `PUPPETEER=... CHROME=... node povedniki/tests/e2e/povedniki.e2e.js`.

## Пересборка

`python3 tools/build_points.py` собирает `data/points.json`, `python3 tools/build_docs.py` собирает `RIGHTS.md`, `SOURCES.md`, `docs/PHOTO_AUDIT.md`.

## Документы

`SOURCES.md` источники и координаты, `RIGHTS.md` права на снимки, `docs/PHOTO_AUDIT.md` проверка фото, `docs/VIDEO.md` про видео.

## Что нужно проверить на месте

Точки поставлены по узлам OpenStreetMap. Радиус «я на месте» 22 м, соседние точки стоят не ближе 26 м. Точки 7 и 8 стоят у храма в 30 м друг от друга, а точка 1 в 29 м от точки 7: у храма GPS может предложить не ту остановку, выбирайте нужную вручную. Улицу переходите только по пешеходному переходу. Пансионаты частные: смотрите с улицы. Доступ к берегу водохранилища может быть закрыт.
