# Симонов монастырь — прогулка с аудиогидом

Статическая страница для телефона. Открывается по QR-коду, приложение ставить не нужно.

## Живой адрес

https://vlk2017.github.io/simonov-excursion/

QR-код: `qr/simonov-excursion.png`

Печатная табличка A5: `qr/tablichka-a5.png` и `qr/tablichka-a5.pdf`

Прежде чем ставить табличку на территории, нужно разрешение настоятеля.

## Как открыть локально

Из этой папки:

```bash
python3 -m http.server 8080
```

Затем на компьютере: http://127.0.0.1:8080/

На телефоне в той же сети — адрес компьютера вместо 127.0.0.1. Для геолокации и камеры нужен HTTPS; на живом адресе выше он уже есть.

## Состав

- `index.html` — страница экскурсии
- `data/points.json` — восемь точек: координаты, тексты и по 3–5 старых фото на точку. У каждого фото есть точка съёмки `viewpoint` (lat, lon, bearing) и подсказка «где встать». У пар «тогда — сейчас» есть параметры совмещения `now.align`
- `audio/heygen/` — рассказы по точкам, голос «Григорий» (HeyGen), 8 файлов mp3 128 кбит/с, 2–2,8 минуты каждый, ~19 МБ всего. Именно их использует сайт (`data/points.json`). Скачаны с исходных ссылок HeyGen 18.11.2026, файлы не менялись
- `audio/*.mp3` — прежние рассказы (edge-tts ru-RU-SvetlanaNeural). Сайтом не используются, оставлены как архив
- `img/then/`, `img/now/`, `img/thumbs/` — старые снимки, современные снимки и превью. Всё взято с Викисклада
- `js/app.js` — интерфейс, карта, GPS, HUD «Веду вас»
- `js/nav-core.js` — чистые функции навигации (расстояния, азимут, декодер polyline6 Valhalla, проекция на маршрут, выбор манёвра, пороги прибытия, уход с маршрута). Без DOM, покрыты тестами
- `tests/` — автотесты (`npm test`, нужен только Node 18+, зависимостей нет) и реальный ответ Valhalla в `tests/fixtures/`
- `sw.js` — офлайн-кэш (версия `simonov-v4`): после первого открытия тексты и фото работают без сети; рассказ кэшируется при первом проигрывании, все рассказы сразу — кнопкой «Скачать рассказы для офлайна (~19 МБ)». Плитки карты и маршрутизатор без сети недоступны
- `screens/` — скриншоты для проверки (390×844)
- `SOURCES.md` — источники фактов
- `RIGHTS.md` — права на фотографии
- `scripts/` — тексты аудио, они же показываются на экране
- `tts/` — версии текстов для синтеза: даты записаны словами, ударения проставлены. Генерируются автоматически
- `qr/` — QR-код и табличка для печати
- `docs/GROK_ROADMAP.md` — техническое задание и дорожная карта

## Как пересобрать озвучку

```bash
python3 -m venv .venv && .venv/bin/pip install edge-tts
.venv/bin/python tools/tts_rebuild.py   # сам запускает tools/tts_normalize.py: scripts/ → tts/ → audio/
```

Это относится к прежним файлам `audio/*.mp3` (edge-tts); текущая озвучка HeyGen сделана вне этого репозитория, исходные тексты — `scripts/`. Ударения задаются в `tools/tts_normalize.py` (список STRESS) знаком ударения U+0301 после гласной. Числа в `scripts/` можно писать цифрами: нормализатор переведёт их в слова в нужном падеже и остановится с ошибкой, если какие-то цифры не сможет прочитать. Проверка распознаванием — faster-whisper (бесплатно, на своём компьютере).

## Как устроена прогулка и что с вашими данными

- Положение берётся из GPS телефона прямо в браузере и никуда на наш сервер не отправляется. Мы не ведём историю перемещений и не подключаем аналитику.
- Чтобы построить пеший путь, в публичный сервис маршрутизации Valhalla (FOSSGIS, `valhalla1.openstreetmap.de`) уходят координаты вашего положения и выбранной остановки. Без этого путь не построить. Это демонстрационный сервис с ограничением нагрузки; при росте посещаемости нужен свой или договорной сервер.
- Карта подгружает плитки OpenStreetMap. Прогресс (какие остановки пройдены) хранится только в браузере телефона (`localStorage`).
- Без сети остаются тексты, фото и скачанные рассказы, но новый маршрут построить нельзя, плитки карты не загрузятся.

## Режим «Веду вас»: как работает

- Путь строится только пешеходный (`costing: pedestrian`), с таймаутом 10 с, отменой старого запроса и защитой от устаревшего ответа. Если маршрутизатор недоступен, показывается сообщение с причиной и ссылка на внешние карты; прямая линия «через здания» не рисуется.
- Подсказка: стрелка, ближайший манёвр и расстояние до него, остаток пути и время (75 м/мин), точность GPS словами.
- Стрелка с компасом: iPhone — `webkitCompassHeading` (разрешение запрашивается кнопкой), Android — `deviceorientationabsolute`. Без компаса стрелка показывает направление относительно севера (вверх — север), и интерфейс об этом говорит. Компас рассчитан на телефон, лежащий горизонтально в портретной ориентации.
- Кнопка «Я на месте» появляется, только если точность GPS не хуже 20 м и до остановки не больше 22 м по прямой. Остановка по GPS сама не отмечается. Отмечается нажатием этой кнопки, кнопки на странице остановки или **по окончании рассказа** (решение владельца от 18.11.2026): после этого навигация переключается на следующую остановку, тост называет её.
- Перестроение: путь перестраивается, если подряд 3 точных (≤30 м) измерения дальше 30 м от линии маршрута и с прошлого запроса прошло не менее 15 с. Одиночный скачок GPS ничего не запускает.

## Тесты

```bash
npm test        # node --test (чистые функции + статические проверки данных и разметки)
npm run check   # проверка синтаксиса JS
```

Автотесты не заменяют полевую проверку: на реальном телефоне навигация пока не проверялась.
